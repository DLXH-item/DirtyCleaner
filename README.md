# 脏数据本地归档工具 v2.0

Windows 原生桌面程序（C# WinForms）。单个 exe，双击即用，不需要安装 .NET 之外的任何东西（Win10/11 自带）。

## 运行方式

- **exe 直接运行**：双击 `脏数据归档工具.exe` 就能用，绿色免安装，不写注册表、不装服务，所有数据都在自己目录里。
- 换电脑：把整个文件夹拷进 U 盘带走，双击 exe 继续用。
- 从源码重新编译（可选，系统自带 csc 即可，不需要 Visual Studio）：

```bat
"C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /target:winexe /codepage:65001 /optimize+ /out:"脏数据归档工具.exe" /reference:System.dll /reference:System.Windows.Forms.dll /reference:System.Drawing.dll "src\DirtyCleaner.cs"
```

## 完全免费开源

MIT 协议，源码全部在本仓库 `src/DirtyCleaner.cs`：单文件、零第三方依赖、不需要 Python / 浏览器 / 安装包，可自由使用、修改、二次分发。

## 代码怎么实现的

- **单文件 C# + WinForms**：没有 NuGet、没有资源文件、没有多文件工程，一个 `.cs` 用系统自带 `csc.exe` 编译成单个 `winexe`，所以是真正的绿色单文件。
- **软件枚举不漏**：`SoftFinder.Enumerate` 合并四路来源——注册表 Uninstall 键（HKLM/HKCU × SOFTWARE\Uninstall + WOW6432Node，过滤 SystemComponent=1）、App Paths 注册表、开始菜单 `.lnk`（WScript.Shell 反射解析 TargetPath）、指定根目录一级子目录；全盘模式下枚举所有固定磁盘一级目录，并对 Packages / Programs / WindowsApps 等集合目录再展开一层。同名、同路径条目按名字评分合并，显示名优先取注册表 / 快捷方式里的中文名，所以安装目录是拼音也不会显示拼音。
- **懒加载不卡**：点选某个软件才在后台线程 `FileScanner.Scan` 递归扫描它，单软件上限 50 万文件、深度 24 层；左右两个列表都是 `VirtualMode + RetrieveVirtualItem`，只绘制可见行；扫描中 700ms tick 增量刷新；搜索 320ms 防抖。
- **三视图**：全部文件 / 按数据分类（缓存临时、日志崩溃、配置数据、程序文件、备份归档、其他，按软件分组内的相对路径判定）/ 按文件类型（扩展名分组按数量降序）；顶部快捷筛选条按面板宽度自适应排布按钮。
- **风险分级防误删**：按扩展名 + 关键字规则给每个文件打三级标签——protected（● 影响使用，红，默认禁止彻底删除，需在确认窗里手动勾选风险确认）、caution（● 谨慎清理，黄）、safe（● 可清理，绿）。
- **归档可还原**：把勾选文件移动到 `<exe目录>\归档隔离区\<软件名>\<相对路径>`，同时往 `归档隔离区\manifest.tsv` 追加 6 列记录（原路径 / 归档路径 / 软件 / 文件名 / 分类 / 时间），还原时按清单原路放回。
- **打开位置 / 刷新**：文件级三处入口（底部按钮、双击行、右键菜单）用 `explorer.exe /select,"<文件>"` 定位；软件级「打开位置」直接进安装目录，「刷新软件」整目录重扫；刷新时先 `FileScanner.PurgeMissing` 剔除磁盘上已删掉的记录，再后台重扫补齐。

## 一、它能做什么

- **自动扫描本机所有软件**：读取注册表已安装程序（含 32/64 位两套卸载键、App Paths）、开始菜单快捷方式，再叠加 Roaming / Local / ProgramData / Program Files / Program Files (x86) 五个默认位置，勾选「全盘」后逐个固定磁盘枚举所有一级目录（常见软件集合目录再展开一层）。同名同路径的条目自动合并，同一款软件不会重复出现。显示名优先取注册表 / 快捷方式里的中文名；安装目录是拼音或英文名时，列表仍按中文名显示。卸载、帮助、手册、修复、隐私浏览这类快捷方式自动过滤，不单独占一条。
- **每个软件分开管理**：点左侧随便一个软件，程序才在后台去扫描它的文件，不会一上来就全盘遍历，所以打开和切换都不卡。
- **一个软件里三种视图**：
  - `全部文件`：该软件目录下的所有文件。
  - `按数据分类`：缓存临时 / 日志崩溃 / 配置数据 / 程序文件 / 备份归档 / 其他，带数量，点顶部彩色按钮就能只看某一类。
  - `按文件类型`：按扩展名分组（dll、exe、log、json、无扩展名…），按数量从多到少。
- **顶部排序**：按名称 / 大小 / 修改时间 / 分类 / 风险 / 类型排序，可切换升序降序；左侧软件列表也能点列头按 文件数 / 占用 / 位置 排序。
- **防误删**：每个文件都带风险标记——`● 影响使用`（红，程序文件 / 配置 / 存档 / 数据库 / 工程文档，默认禁止彻底删除）、`● 谨慎清理`（黄）、`● 可清理`（绿）。
- **单选 / 多选**：点最左边 □ 勾选单个文件；「全选当前」勾选当前视图里的全部；「取消勾选」清空勾选；勾选状态跨视图、跨搜索保留。
- **归档（可还原）**：把勾选的文件移动到 exe 同目录的 `归档隔离区\<软件名>\…`，并写清单 `manifest.tsv`，随时点「还原已归档」原路放回去。
- **彻底删除**：受保护文件默认拦住；确实要删需要在确认窗里手动勾选风险确认。
- **打开文件所在位置**：底部按钮、双击行、右键菜单三个入口，直接在资源管理器里定位到该文件。
- **刷新文件列表**：你在资源管理器里删完文件回到这里，点底部「刷新文件列表」或按 F5，程序会先立刻把磁盘上已不存在的记录剔除（列表马上少掉），再在后台整目录重扫一遍，把新出现或大小变化的文件补进来，文件数和占用同步更新。
- **软件本身也能操作**：左侧每个软件都有「打开位置」（进到它的安装目录）和「刷新软件」（重扫这款软件的全部文件，文件数/占用一起更新）；右键菜单同样有这两项，另外双击软件行也能直接打开它的目录。
- **界面不卡**：左右两个列表都是虚拟列表（只绘制可见行），扫描在后台线程，边扫边增量刷新；搜索带 320ms 防抖。

## 二、怎么用

1. 双击 `脏数据归档工具.exe`，等左上角「软件 x 个」数字出来（一般 1 秒内）。
2. 需要覆盖更多位置：点「添加目录…」自己加扫描根；或勾选「全盘」后点「重新枚举软件」。
3. 在「软件筛选」里输入名字找目标软件，点它 → 右侧开始扫描并显示文件。
4. 切「视图」看分类或类型；点顶部彩色按钮快速过滤某一类。
5. 勾选要处理的文件 → 「归档所选（可还原）」或「彻底删除所选」。
6. 用资源管理器删过文件后回来，点「刷新文件列表」（或 F5）→ 已不存在的文件立刻从列表消失，再自动补扫新文件。
7. 只想重扫某一款软件：左侧选中它 → 点「刷新软件」（或右键「刷新该软件」）；想进它的安装目录 → 点「打开位置」或双击该行。
8. 想撤销归档：「还原已归档」；想直接看隔离区：「打开隔离区」。

## 四、说明

- 程序不写注册表、不装服务，所有数据都在自己目录里，拷走整个文件夹即完整迁移。
- 扫描结果只是「文件清单」，不会自动删除任何东西；删除/归档都要你亲手点。
- 受保护的识别是按扩展名 + 关键字规则判断的：`.exe .dll .sys .db .mdb .sln .vcxproj .psd .doc .xls .ppt …`，以及名字里带 `config / settings / save / profile / license / key` 的。
- 全盘扫描只枚举「目录」层级，不会预先遍历所有文件，所以速度只跟磁盘目录数量有关。
- 单个软件的文件数上限 50 万，达到上限时状态栏会提示「已达上限」。
